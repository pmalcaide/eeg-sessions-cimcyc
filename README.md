# EEG+ Sessions

Open materials from the **EEG+ Sessions** at CIMCYC: meetings for researchers of all levels interested in time-resolved neuroimaging (EEG, iEEG, MEG, eye-tracking and more) to learn, share ideas and solve everyday research challenges in a friendly, open environment.

Materials are organised by topic. Each topic folder has everything about it: the sessions we held, the slides, the code and the suggested readings. Notebooks open directly in Google Colab, so there is nothing to install.

## Session formats

| Format | What happens |
|:--|:--|
| **Talks** | Someone presents their project, followed by discussion |
| **Problem-solving sessions** | Bring questions about your paradigm, data, results or analyses for group feedback |
| **Workshops** | Hands-on work with toolboxes and analyses |
| **Journal clubs** | We discuss a suggested reading |

## Using the materials

- **Notebooks:** click the *Open in Colab* badge in a topic folder, then use **File → Save a copy in Drive** to keep your own editable copy.
- **Everything at once:** use the green **Code** button at the top of this page and choose **Download ZIP**, or clone the repository with Git.
- **General tools and references:** see [RESOURCES.md](RESOURCES.md).
