# Resources

General tools and references that come up across sessions. Suggestions welcome.

## Analysis toolboxes

- [MNE-Python](https://mne.tools): EEG/MEG/eye-tracking analysis in Python (used in our workshop notebooks)
- [EEGLAB](https://eeglab.org): MATLAB toolbox with a graphical interface
- [FieldTrip](https://www.fieldtriptoolbox.org): MATLAB toolbox for MEG/EEG/iEEG

## Running the notebooks

- [Google Colab](https://colab.research.google.com): runs Python notebooks in the browser with a Google account

## Data standards and open data

- [BIDS](https://bids.neuroimaging.io): a standard way to organise neuroimaging datasets, including EEG, iEEG and MEG
- [OpenNeuro](https://openneuro.org): public BIDS datasets you can practise on
